# Troubleshooting

Start with the exact version, supported environment, failing step, expected result, and sanitized evidence. Never publish credentials, personal data, private paths, signing material, copyrighted fixtures, or vulnerability details.

For 1.0.2, a first-launch Gatekeeper warning can reflect its disclosed ad-hoc,
non-notarized distribution. Follow [Getting Started](Getting-Started) only
after checking that you trust the official download. Cadence 1.0.2 is the
current public release. Existing Cadence installations can receive the
EdDSA-signed update through **Cadence > Check for Updates…**.

Use the canonical [troubleshooting guide](https://github.com/QenTerra/cadence/blob/main/docs/TROUBLESHOOTING.md), [support policy](https://github.com/QenTerra/cadence/blob/main/SUPPORT.md), and [security policy](https://github.com/QenTerra/cadence/blob/main/SECURITY.md).
