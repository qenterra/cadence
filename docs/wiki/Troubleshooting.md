# Troubleshooting

Start with the exact version, supported environment, failing step, expected result, and sanitised evidence. Never publish credentials, personal data, private paths, signing material, copyrighted fixtures, or vulnerability details.

For 1.0.0, a first-launch Gatekeeper warning can reflect its disclosed ad-hoc,
non-notarized distribution. Follow [Getting Started](Getting-Started) only
after checking that you trust the official download. If Check for Updates
does not offer 1.0.0, install it manually; this release does not update Sparkle.

Use the canonical [troubleshooting guide](https://github.com/QenTerra/cadence/blob/main/docs/TROUBLESHOOTING.md), [support policy](https://github.com/QenTerra/cadence/blob/main/SUPPORT.md), and [private security route](https://github.com/QenTerra/cadence/security/advisories/new).
