# Getting Started

## Requirements

Apple silicon Mac with macOS 26 or later for use; full Xcode and the declared development tools for source verification.

## Install a release

Download the DMG attached to a supported GitHub Release, drag Cadence to Applications, and launch it from there. The current beta is Apple silicon only. If Gatekeeper or signature verification does not match the release notes, stop and report the exact asset and checksum.

## First successful path

Choose or create a `Cadence.library` folder, import supported audio, and begin playback from the managed library. Cadence copies selected content into that folder; it does not upload the library or operate a developer backend. Review [Privacy](https://github.com/QenTerra/cadence/blob/main/PRIVACY.md) before connecting optional external providers.
