# Release Process

Releases use `semver`, the version source `release-contract.json`, curated changelog entries, exact revision verification, profile-specific artifact checks, and post-publication remote verification.

Read the canonical [release guide](https://github.com/QenTerra/cadence/blob/main/docs/RELEASING.md) and [changelog](https://github.com/QenTerra/cadence/blob/main/CHANGELOG.md). A GitHub Wiki page does not grant authority to tag, publish, deploy, or alter update metadata.
