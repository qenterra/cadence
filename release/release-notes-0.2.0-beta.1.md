# Cadence 0.2.0 Beta 1

The first installable Cadence beta for Apple silicon.

- Open AAC, AIFF, FLAC, M4A, MP3, and WAV files directly from Finder without
  importing them or scanning nearby folders.
- Add only the current external track to the managed library with the explicit
  **Add to Library…** action.
- Install through a restrained monochrome Soft Graphite DMG.
- Receive opt-in beta updates through Sparkle.

Publish this draft only with the Developer ID signed and notarized artifacts
produced by the public release path. Verify the published SHA-256 checksum,
open the DMG, and drag Cadence to Applications.
